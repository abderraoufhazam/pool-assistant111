# دليل البناء عبر الإنترنت (GitHub Actions) — بدون Android Studio

هذا الدليل يشرح كيف تبني ملف **APK** لتطبيق Pool Assistant **بدون تثبيت Android Studio على جهازك**، باستخدام GitHub Actions (خدمة سحابية مجانية).

---

## المتطلبات (مرة واحدة فقط)

1. **حساب GitHub** (لديك حساب جاهز).
2. متصفح إنترنت.
3. ملفات المشروع الموجودة في هذا المجلد.

---

## الخطوة 1: رفع المشروع إلى GitHub

### الطريقة أ: عبر موقع GitHub (أسهل — بدون أوامر)

1. ادخل إلى https://github.com وسجّل الدخول.
2. اضغط زر **New repository** (+ في أعلى اليمين).
3. سمّه مثلاً `pool-assistant` واتركه **Public** (ضروري ليكون الرصيد المجاني كافياً) واضغط **Create repository**.
4. في الصفحة الجديدة اضغط رابط **uploading an existing file** (أو **Add file → Upload files**).
5. اسحب **مجلد `POOL-ASSISTANT`** كاملاً (بكل ملفاته بما فيها المجلد المخفي `.github`) وأفلته في نافذة الرفع. 
   - ⚠️ تأكد أن ملف `.github/workflows/build-apk.yml` مرفوع — إن لم يظهر لك المجلد `.github` (لأنه مخفي)، ارفع ملفاته يدوياً.
6. اضغط **Commit changes**.

### الطريقة ب: عبر سطر الأوامر (اختياري)

إذا كان عندك Git مثبّتاً:

```bash
cd POOL-ASSISTANT
git init
git add .
git commit -m "Pool Assistant: initial project"
git branch -M main
git remote add origin https://github.com/اسمك/pool-assistant.git
git push -u origin main
```

---

## الخطوة 2: تشغيل البناء

بمجرد رفع الملفات (أو الدفع)، سيعمل **GitHub Actions** تلقائياً لأنه وجد ملف
`.github/workflows/build-apk.yml`.

لمتابعة النتيجة:

1. من صفحة المستودع (repository) اضغط تبويب **Actions**.
2. سترى سير العمل باسم **Build Debug APK** وهو يعمل (أيقونة صفراء تعني "قيد التشغيل"، خضراء "نجح"، حمراء "فشل").
3. انتظر حتى يتحول إلى ✅ (غالباً 3–7 دقائق).

---

## الخطوة 3: تحميل ملف APK

1. افتح سير العمل الناجح (اضغط على اسمه).
2. في أسفل الصفحة ستجد قسم **Artifacts** وفيه ملف **PoolAssistant-debug-apk**.
3. اضغط عليه لتحميله (ملف ZIP).
4. فك الضغط وستجد بداخله `app-debug.apk`.

---

## الخطوة 4: تثبيته على هاتفك

1. انقل `app-debug.apk` إلى هاتفك.
2. افتحه ووافق على "التثبيت من مصادر غير معروفة".
3. افتح **POOL ASSISTANT** واتبع خطوات منح الصلاحيات.

---

## إذا فشل البناء (أيقونة حمراء ❌)

1. افتح سير العمل الفاشل.
2. اضغط على خطوة **Build debug APK** لعرض سجل الأخطاء.
3. انسخ رسالة الخطأ وأرسلها للمساعدة (أنا سأصلحها لك).

---

## ملاحظة صادقة

- أول عملية بناء على GitHub قد تُظهر أخطاء تجميع بسيطة (طبيعي لمشروع كُتب
  دون بيئة تجريب مسبقاً). أي خطأ يظهر يُصلح بسرعة بإرسال نصه.
- البناء المجاني يتطلب أن يكون المستودع **Public**. المستودعات Private لها
  حدود دقائق مجانية أقل لكنها تكفي عادة لبنائين أو ثلاثة شهرياً.
